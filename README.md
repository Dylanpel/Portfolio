# Portfolio — Dylan Peltier
 
Site portfolio personnel d'un développeur web en reconversion : présentation, compétences, projets, parcours et contact. Le site est une application React à page unique, avec une seconde page pour les mentions légales.
 
**Site en ligne :** https://dylan-peltier.fr
 

## Fonctionnalités
 
- Page unique avec navigation vers les sections : À propos, Projets, Compétences, Parcours, Contact
- Mise en page responsive (mobile, tablette, ordinateur) avec la grille Bootstrap
- Menu de navigation fixe qui se replie en menu burger sur petit écran
- Cartes de projets générées à partir d'un tableau de données
- Parcours en deux colonnes : diplômes et formations, expériences professionnelles
- Liens de contact : e-mail, CV, GitHub et LinkedIn
- Page de mentions légales
## Technologies
 
- [React](https://react.dev/) et [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev/) pour le développement et le build
- [Bootstrap](https://getbootstrap.com/) pour la grille et les composants
- [React Router](https://reactrouter.com/) pour la navigation entre les pages
- [Font Awesome](https://fontawesome.com/) (icônes gratuites) pour les icônes
- Polices Open Sans et JetBrains Mono, hébergées dans le projet
 
## Structure du projet
 
```
src/
├── assets/fonts/   Polices du site
├── components/     Composants (Navbar, Hero, About, Projects, ProjectCard, Parcours, Contact, MentionsLegales…)
├── main.tsx        Point d'entrée
└── …               Feuilles de style
public/             Fichiers servis tels quels (CV, favicon)
```
 
> À adapter : ajustez les noms de dossiers à l'arborescence réelle de votre projet.
